# SQL Detective — Petty Offenses Division

Оригинальная игра-головоломка про SQL: вы — детектив «Отдела мелких преступлений» города Los Datos.
Читаете улики, пишете SQL-запросы к базам данных и арестовываете виновного.
Игра работает **полностью локально и офлайн** — никаких серверов и установки.

## Как запустить

Просто откройте файл **`index.html`** в браузере (Chrome, Firefox, Edge, Safari) — двойным кликом.
Сервер не нужен. Прогресс сохраняется в браузере (localStorage).

## Как играть

1. На рабочем столе откройте **messages** — инструктаж от помощника, офицера Спада.
2. **clues** — улики по делу. **manual** — учебник по SQL (растёт от дела к делу).
3. Иконки таблиц (например `residents`) — данные дела. Двойной клик по строке с человеком открывает его досье.
4. **search** — окно запросов (`Ctrl+Enter` — выполнить). Ошибки объясняются простыми словами.
   Можно сохранить результат как новую таблицу («Save Table»).
5. Нашли виновного — **arrest**, впишите полное имя и подайте ордер.
6. Нужна помощь — кликните по Споду внизу справа: он даёт подсказки (они влияют на звёзды).

## Дела

| # | Дело | Чему учит |
|---|------|-----------|
| 1 | Gnome Alone | SELECT, FROM, WHERE, AND |
| 2 | The Soggy Sandwich Scandal | LIKE, BETWEEN, != |
| 3 | Checkout Chaos | ORDER BY, LIMIT |
| 4 | The Cookie Jar Heist | COUNT, GROUP BY, HAVING, арифметика, подзапросы |
| 5 | Overdue at the Library | JOIN (3 таблицы) |
| 6 | Parking Meter Mayhem | JOIN + улики из «интернета» (web browser) |

Звёзды за дело: 3 — без подсказок и ошибочных арестов, меньше — за каждую подсказку/ошибку.
Все дела открываются по очереди; в настройках есть «Unlock all cases».

## Для разработчиков

* `js/cases.js` — данные дел (генерируются детерминированно, виновный гарантированно один).
* `js/game.js` — интерфейс «рабочего стола», окна, SQL-терминал, дружелюбные ошибки.
* `js/chars.js` — персонажи и иконки (SVG, без картинок).
* `js/sql-asm.js` — [sql.js](https://github.com/sql-js/sql.js) (SQLite, asm.js-сборка, работает с `file://`).
* Проверка всех дел настоящим SQL: `node tests/verify-cases.js`

Все персонажи, сюжеты и рисунки — оригинальные. Игра вдохновлена идеей игр вроде *Database Detective*, но не использует их материалы.
